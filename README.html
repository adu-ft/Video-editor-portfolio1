High-impact, cinematic portfolio built with React 19, TypeScript & Tailwind CSS

Instagram: @adu.ft GitHub: adrix-ft React 19 Tailwind v4 Vite

🌟 Overview

This website serves as a flagship digital portfolio for Adarsh Yadav, a seasoned video editor who turns raw footage into cinematic stories. The design features a bold, high-contrast dark aesthetic with vibrant coral accents, smooth scroll animations, interactive video previews, and seamless client inquiries.

✨ Key Interactive Features

Feature Description
Hero Header Banner Editorial portrait hero banner with dark vignette, floating green availability badge, and quick navigation menu.
Transform Title with Media Capsules Syne display typography containing live raw clip and cinematic video capsules with click-to-preview lightbox reel.
Continuous Moving Marquee Infinite loop ribbon showcasing international partner logos with edge gradient fading and hover pause.
About Me & Typography Reveal High-contrast white section with word-by-word blur dissolve text reveal, 3D Framer isometric cube card, and philosophy columns.
Featured Work Grid Interactive project cards with categories (VFX, Commercial, Title Animation, Trailers) and instant video playback modal.
Stats & Facts Dynamic number counter animations counting up on scroll (13+ Projects, 8+ Years, 10+ Recognitions, 13% Growth).
Pro Services & Pricing Service packages with starting prices, capability details, and 1-click inquiry routing.
Client Testimonials 5-star client ratings with creator names and personalized reviews.
Contact Form Interactive project collaboration form with real-time feedback and worldwide support guarantees.
FAQ & Desk Setup Collapsible accordions accompanied by high-res video editing studio desk setup photography.
Footer & Social Links Direct links to GitHub (adrix-ft) and Instagram (@adu.ft).

🛠️ Tech Stack

  • Frontend: React 19 SPA with TypeScript
  • Styling: Tailwind CSS v4 with bespoke cubic-bezier animations
  • Icons: Lucide React
  • Motion: Hardware-accelerated IntersectionObserver with compositor-only properties
  • Typography: Syne & Plus Jakarta Sans

🚀 Running Locally

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
