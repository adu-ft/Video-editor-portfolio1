<h2>🛠️ Tech Stack & Architecture</h2>

<ul>
  <li><strong>Framework:</strong> React 19 SPA (Functional components with modern hooks)</li>
  <li><strong>Build Tool:</strong> Vite 8 (Ultra-fast HMR and optimized production bundles)</li>
  <li><strong>Language:</strong> TypeScript (Strict mode enabled, full interface typing)</li>
  <li><strong>Styling:</strong> Tailwind CSS v4 + Custom Keyframes for Marquees and 3D Transforms</li>
  <li><strong>Typography:</strong> Google Fonts — <em>Syne</em> (Display/Headlines) & <em>Plus Jakarta Sans</em> (Body)</li>
  <li><strong>Icons:</strong> Lucide React</li>
  <li><strong>Motion:</strong> Hardware-accelerated IntersectionObserver with compositor-only properties</li>
</ul>

<h2>🚀 Getting Started</h2>

<h3>Prerequisites</h3>
<ul>
  <li>Node.js (v18.0.0 or higher)</li>
  <li>npm, pnpm, or bun</li>
</ul>

<h3>Installation & Running Locally</h3>

<pre><code># 1. Clone repository
git clone https://github.com/adrix-ft/mateo-diaz-portfolio.git

# 2. Navigate to project root
cd mateo-diaz-portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
</code></pre>

<h3>Deploying to Vercel</h3>
<ol>
  <li>Import the repository into <a href="https://vercel.com">Vercel</a>.</li>
  <li>Framework Preset: <strong>Vite</strong>.</li>
  <li>Build Command: <code>npm run build</code></li>
  <li>Output Directory: <code>dist</code></li>
  <li>Install Command: <code>npm install</code> (configured via <code>.npmrc</code> and <code>vercel.json</code>).</li>
</ol>
